02 · Environment, criteria & risks

The manual round and the Appium suite both ran on the physical Xiaomi 24117RN76G (Android 16, 1080×2400), which makes the manual and automated results comparable rather than anecdotal — see the evidence page. The Test Plan sheet lists the originally planned emulators; the round was executed on hardware.

8. Risks & mitigations

KeyItemDetail
R1TheMealDB is a free third-party API and can rate-limit or go down.The repository falls back to the shared_preferences cache; TC_HOME_003 covers it.
R2Firebase App Distribution shares the same project as the course.Emails are restricted per tester group; documented in the README.
R3Google Play Services are missing on some emulators, breaking the map.MapErrorBoundary renders a friendly panel; TC_MAP_004 covers it.
R4local_auth behaves differently when no fingerprint is enrolled.The gate offers an explicit bypass; TC_PROFILE_003 covers it.
