16 · Class and type index16 · فهرس الأصناف والأنواع

Every class, enum and extension declared under lib/, in one searchable table: 274 types — 245 plain classes, 8 sealed, 10 abstract, 2 final, 4 enums and 5 extensions. 61 of them are private (their name starts with _) and exist only inside the file that declares them.

Rows are not translated: a type name and its file:line mean the same thing in either language, and inventing a sentence per type would only add drift. What this index gives you instead is the inheritance and mapping graph — the fourth column is the extends / implements / on tail exactly as written (— when the type stands alone), so MealModel tells you itself that it extends MealEntity.

Sort order is folder, then the declaration line in the file, so a feature's types sit together: a Cubit, its states, the screen that watches it.

كل class وenum وextension مُصرَّح عنه تحت lib/ في جدول واحد: 274 نوعًا — 245 صنفًا عاديًا، و8 مغلقًا، و10 مجرّدًا، و2 نهائيًا، و4 تعدادًا، و5 امتدادًا. و61 منها خاص (يبدأ اسمها بـ_) ولا وجود له خارج الملف الذي صرّح عنه.

السطور غير مترجمة عمدًا: اسم الصنف وملف:سطر يعنيان الشيء نفسه في اللغتين، واختراع جملة لكل صنف لن يزيد إلا انحرافًا. ما يعطيه هذا الفهرس بدل ذلك هو رسم التوريث والتحويل — فالعمود الرابع هو ذيل extends وimplements وon كما كُتب حرفيًا (— إن كان الصنف واقفًا وحده)، وبهذا يقول MealModel بنفسه إنه يمتدّ من MealEntity من غير أن يحتاج أحدًا ليخبره.

والترتيب حسب المجلد ثم حسب سطر التصريح في الملف، فتجلس أنواع الميزة الواحدة معًا: Cubit، فحالاته، فالشاشة التي تُصغي إليه.

16.9 · What the names tell you16.9 · ما تقوله الأسماء

The naming scheme is the layering contract in miniature: reading a name is usually enough to know which layer a type belongs to and what it may depend on. These seven shapes cover essentially all of lib/.

مخطط التسمية هو عقدُ الطبقات في مصغّر: تكاد قراءة الاسم وحده تغني عن معرفة الطبقة التي ينتمي إليها هذا الصنف وما الذي يُسمح له بالاعتماد عليه. وهذه الأشكال السبعة تغطي lib/ كلها تقريبًا.

Suffix or shapeاللاحقة أو الشكلWhat it guaranteesما يضمنه
…Entity…كيانWhat the app knows about a thing, in pure Dart with no Flutter or cloud import. A screen may hold one; it may never build one from a wire response.ما يعرفه التطبيق عن الشيء، بلغة Dart خالصة بلا استيراد Flutter أو السحابة. يجوز أن تملك الشاشة واحدًا، ولا يجوز أن تبنيه من ردّ الشبكة.
…Model…نموذجThe same shape plus fromJson/toFirestore. Always declared as class XModel extends XEntity, so the compiler proves the wire type can stand in for the domain type.الشكل نفسه مع fromJson وtoFirestore. يُصرَّح دائمًا بـclass XModel extends XEntity، فيُثبت المترجم أن نوع السلك يصلح بدل نوع النطاق.
…Repository / RepositoryImpl…مستودع / تنفيذ مستودعThe abstract half lives in domain/repositories/ and says only what can fail; the …Impl half lives in data/repositories/ and owns the choice of data source. Nothing imports the Impl.النصف المجرّد في domain/repositories/ ويقول ما يمكن أن يفشل فقط؛ والنصف …Impl في data/repositories/ ويملك اختيار مصدر البيانات. ولا شيء يستورد التنفيذ.
…Cubit / Bloc + _state / _event…كيوبت / بلوك + حالة / حدثOne controller per feature folder, and its states in a sibling file. Every state file starts with a sealed class, which is what makes an unhandled branch a compile error rather than a runtime surprise.متحكّم واحد لكل مجلد ميزة، وحالاته في ملف مجاور. ويبدأ كل ملف حالة بـsealed class، وهذا ما يجعل الفرع غير المعالج خطأ ترجمة لا مفاجأة تشغيل.
…UseCase + Params…حالة استخدام + وسائطclass Foo implements UseCase<T, P> with the params as a nested or sibling Equatable. The verb is in the name (AddToCart, GetMeals), and the return type is always Either<Failure, T>.class Foo implements UseCase<T, P> مع الوسائط كصنف Equatable تابع أو مجاور. والفعل في الاسم (AddToCart، GetMeals)، ونوع الإرجاع دائمًا Either<Failure, T>.
…Failure…فشلOne per recoverable error, each carrying an ARB messageKey so the UI can localise it without knowing what happened.واحد لكل خطأ يمكن تجاوزه، ويحمل كلٌّ منها messageKey من ARB لتستطيع الواجهة ترجمته وهي لا تعرف ما جرى.
…Leading underscore…شرطة سفلية في أول الاسمA library-private type. Two shapes: the generated _State of a StatefulWidget, and the sub-widget a screen extracted because the file was getting long.نوع خاص بالمكتبة. وله شكلان: _State المولّد لـStatefulWidget، ودجة فرعية فصلتها شاشة لأن ملفها بدأ يطول.
