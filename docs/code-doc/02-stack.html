02 · Tech stack02 · التقنيات المستخدمة

StreetBite is a Flutter app targeting Android only. The runtime is Dart with sound null safety, compiled ahead-of-time into a release APK. Every third-party capability is reached through one of our own classes, so no plugin type appears in the domain or presentation layers.

The state layer is flutter_bloc: one Bloc (the cart, because checkout is a real transaction) and seven Cubits. Identity and persistence are Firebase. The menu feed is a public REST API reached through Dio. The frosted look is delegated to a glass widget package with an adaptive quality mode.

StreetBite تطبيق Flutter يستهدف أندرويد فقط. بيئة التشغيل هي Dart مع سلامة نوع صارمة Null Safety، وتُترجم قبل التنفيذ إلى ملف APK نهائي. كل قدرة خارجية يمر بها التطبيق عبر أحد أصنافنا الخاصة، لذلك لا يظهر نوع أي إضافة في طبقة Domain ولا في طبقة Presentation.

طبقة الحالة هي flutter_bloc: Bloc واحد (السلة، لأن إتمام الطلب معاملة حقيقية) وسبعة Cubits. الهوية والتخزين لدى Firebase. وبيانات الأطباق تأتي من واجهة REST عامة نصل إليها عبر Dio. أما الشكل الزجاجي فينفذه liquid_glass_widgets مع وضع جودة متكيّف.

Outside the Flutter projectخارج مشروع Flutter

  • Java 17 + Maven + TestNG + Appium (UiAutomator2) in automation/ — the device-level suite that drives the installed APK.
  • Python in manual_qa/scripts/ — four builders that generate and patch the QA workbook and the closure PDF.
  • Firebase Console — Auth providers enabled, Firestore rules deployed from streetbite_capstone/firestore.rules.
  • Figma in figma/ — the design source the palette and the tab bar came from.
  • No CI — every check (dart format, flutter analyze, flutter test, flutter build apk) is run by hand.
  • Java 17 و Maven و TestNG و Appium (UiAutomator2) في automation/ — حزمة الاختبار على مستوى الجهاز التي تُشغل ملف APK المثبت.
  • Python في manual_qa/scripts/ — أربعة مولدات تنشئ وتصلح مصنف جودة الاختبار وملف الإغلاق بصيغة PDF.
  • وحدة تحكم Firebase — تفعيل مزودي المصادقة ونشر قواعد Firestore من streetbite_capstone/firestore.rules.
  • Figma في figma/ — مصدر التصميم الذي أُخذت منه الألوان وشريط التبويب.
  • لا يوجد تكامل مستمر CI — كل فحص (dart format وflutter analyze وflutter test وflutter build apk) يُنفَّذ يدويًا.
