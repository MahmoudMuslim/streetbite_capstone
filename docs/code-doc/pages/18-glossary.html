18 · Glossary18 · المعجم

Every term this document uses in a sense specific to StreetBite, plus the few general ones it assumes. Each entry points back at the section that argues the point, because in this code base a word is defined by the rule attached to it, not by the dictionary.

كل مصطلح تستعمله هذه الوثيقة بمعنى خاص بـ StreetBite، مع القليل من المصطلحات العامة التي تفترضها. وكل مدخل يشير إلى القسم الذي يبرهن الفكرة، لأن الكلمة في هذا الكود تُعرَّف بالقاعدة المعلقة عليها لا بالقاموس.

Architectureالبنية

Termالمدخل In this project it meansمعناه في هذا المشروع
Clean Architecture Four folders — core, data, domain, presentation — with one legal import direction, enforced by review rather than by a linter (§3). أربعة مجلدات — core وdata وdomain وpresentation — باتجاه استيراد قانوني واحد، يحرص عليه المراجعة لا المُحلِّل (§3).
domain purity Measured, not claimed: the layer imports zero Flutter, zero Dio, zero cloud_firestore, and one pub package — equatable (§8, §15.4). مقيس لا معلن: فالطبقة لا تستورد Flutter ولا Dio ولا cloud_firestore، وتستورد حزمة pub واحدة هي equatable (§8، §15.4).
Composition root lib/injection.dart and its 45 GetIt registrations: the only file allowed to know which implementation backs which contract (§4). lib/injection.dart وتسعة وأربعون تسجيلًا في GetIt: الملف الوحيد المسموح له بمعرفة أي تنفيذ يقف خلف أي عقد (§4).
Either<L, R> The sealed two-case return type every use case answers with: Left is a Failure, Right is data. Chosen over Dart exceptions so a failure has to be handled where it is caught (§6). نوع الإرجاع المغلق بحالتين الذي تجيب به كل حالة استخدام: Left فشل وRight بيانات. واختير بدل استثناءات Dart ليُعالَج الفشل حيث يُمسك (§6).
Failure A sealed hierarchy of recoverable errors, each carrying an ARB messageKey. Exceptions never cross a repository boundary (§6, §17.1). هرم مغلق للأخطاء الممكن تجاوزها، يحمل كل منها messageKey من ARB. ولا تعبر الاستثناءات حدّ المستودع (§6، §17.1).
Use case One verb, one call(), twenty files in domain/usecases/. A screen talks to these, never to a repository directly (§5, §8). فعل واحد وcall() واحد، في عشرين ملفًا تحت domain/usecases/. تكلم هذه الشاشاتُ لا المستودعات مباشرة (§5، §8).
Params The typed argument object a use case takes; NoParams when it takes nothing. The only domain types a screen is allowed to construct by hand (§16.9). كائن الوسيط المُصنَّف الذي تأخذه حالة الاستخدام؛ وNoParams إن لم تأخذ شيئًا. وهي أنواع النطاق الوحيدة التي يُسمح للشاشة بإنشائها يدويًا (§16.9).
Repository vs …Impl The contract names what can fail; the implementation, in data/repositories/, owns the choice of data source. Nothing imports the Impl (§7, §16.9). العقد يسمّي ما يمكن أن يفشل؛ والتنفيذ في data/repositories/ يملك اختيار مصدر البيانات. ولا شيء يستورد التنفيذ (§7، §16.9).
Entity vs Model Entity is what the app knows; XModel extends XEntity adds the wire format. The compiler therefore proves a model can stand in for its entity (§8, §16.9). الكيان ما يعرفه التطبيق؛ ويضيف XModel extends XEntity شكل السلك. فيُثبت المترجم أن النموذج يصلح بدل كيانها (§8، §16.9).
Data source Eleven of them: Dio for TheMealDB, the two on-device stores, the Firestore gateway, the biometric and photo services. Each knows one system (§7). أحد عشر مصدرًا: Dio لـ TheMealDB، ومتجران على الجهاز، وبوابة Firestore، وخدمتا البصمة والصورة. وكل واحد يعرف نظامًا واحدًا (§7).

State and navigationالحالة والتنقّل

Termالمدخل In this project it meansمعناه في هذا المشروع
Cubit Eight of them, all rooted above MaterialApp except ProfileCubit, which is scoped to its own screen so leaving the tab disposes it (§5, §15.6). ثمانية كلها تحت MaterialApp إلا ProfileCubit فيحده شاشة واحدة، فمغادرة التبويب تغلقه (§5، §15.6).
Bloc Exactly one: CartBloc. It is a Bloc because checkout is a transaction with events, not a single value swap (§5, §13). واحد بالضبط: CartBloc. وهو Bloc لأن إتمام الطلب معاملة بأحداث لا تبديل قيمة (§5، §13).
Sealed state Every *_state.dart opens with sealed class, so a new state that no when arm handles is a compile error (§5, §6). كل *_state.dart يفتتح بـsealed class، فتكون حالة جديدة بلا فرع when يعالجها خطأ ترجمة (§5، §6).
IndexedStack shell The four-tab body that keeps every tab alive, so Home keeps its scroll offset and its banner page (§12). Tabs are addressed by index, and the shell is the only thing that knows them (§12). هيكل التبويبات الأربعة الذي يبقي كل تبويب حيًا، فتحتفظ الرئيسية بموضع تمريرها وصفحة بانرها (§12). ويخاطَب التبويب بالدليل لا بالاسم، والهيكل وحده يعرف التبويبات (§12).
onGenerateRoute One switch over twelve route names, with default landing on splash. An unknown or mistyped deep link therefore shows the splash, never a red screen (§12). تبديل واحد على اثني عشر اسم مسار، وفرع default إلى البداية. فالرابط المجهول أو المكتوب خطأً يُظهر شاشة البداية لا الشاشة الحمراء (§12).
Route arguments Always a List whose first element is the payload: arguments: [meal], never arguments: meal. Two screens accept a missing argument and mount a placeholder instead (§12). قائمة دائمًا أول عناصرها الحمولة: arguments: [meal] لا arguments: meal. وشاشتان تقبلان الوسيط الناقص وتُركّبان بديلًا (§12).
AppPageRoute The single PageRouteBuilder every screen arrives through: 320 ms fade with a 0.035 slide, keeping Hero flights alive (§12). PageRouteBuilder الوحيد الذي تصل عبره كل شاشة: تلاشٍ 320 ملّي ثانية مع انزلاق 0.035، فيبقى طيران Hero حيًا (§12).
Hero One tag pattern, 'meal-image-${meal.id}', shared by the card, the banner page and the details screen. نمط وسم واحد، 'meal-image-${meal.id}'، تتشاركه البطاقة وصفحة البانر وشاشة التفاصيل.
The biometric gate Not a screen but a wrapper: tapping the avatar runs BiometricGate, and a failed scan falls back to the password form without signing the user out (§11). ليست شاشة بل غلاف: النقر على الصورة يشغّل BiometricGate، والفحص الفاشل يرجع إلى نموذج الكلمة دون إخراج المستخدم (§11).

Look and languageالمظهر واللغة

Termالمدخل In this project it meansمعناه في هذا المشروع
Appearance Four of them — light, dark, glass light, glass dark — one AppThemeMode enum value each. "Theme" in the Settings UI means this, not brightness (§9). أربعة مظاهر — فاتح وداكن وزجاجي فاتح وزجاجي داكن — لكل منها قيمة في تعداد AppThemeMode. و«السمة» في واجهة الإعدادات تعني هذا لا السطوع (§9).
Liquid Glass The refractive look from liquid_glass_widgets: an aurora backdrop behind an opaque Navigator, plus a GlassTabBar. It changes the widget structure, not just the palette (§9, §12). المظهر الانكساري من liquid_glass_widgets: خلفية شفقية خلف Navigator معتّم، وGlassTabBar. وهو يغيّر هيكل الودجات لا اللوحة وحدها (§9، §12).
Theme extension AppGlassTokens is a ThemeExtension, which is how a widget asks "is glass on?" without importing a singleton (§9). AppGlassTokens هو ThemeExtension، وبه يسأل الودجت «هل الزجاج مفعّل؟» دون استيراد نظير واحد (§9).
Bottom clearance 104 px published through MediaQuery.padding.bottom so a floating glass bar costs the scrolling content nothing but its height (§9, §12). 104 بكسل تُنشر عبر MediaQuery.padding.bottom، فلا تكلّف الشريط الزجاجي العائم المحتوى المارّ إلا ارتفاعه (§9، §12).
ARB · .arb The JSON template format Flutter's localiser reads. 178 keys in each of app_en.arb and app_ar.arb; equal counts are enforced by the generator (§10, §17.5). صيغة القوالب JSON التي يقرؤها مُولِّد الترجمة. و178 مفتاحًا في كل من app_en.arb وapp_ar.arb؛ وتساوياهما يضمنه المولّد (§10، §17.5).
L10nX The extension that is the only bridge from a message key to a sentence, and the place where the one known missing arm lives (§10, §17.5). الامتداد الذي هو الجسر الوحيد من مفتاح الرسالة إلى الجملة، والموضع الذي فيه الفرع الناقص المعروف (§10، §17.5).
RTL flip Handled by Flutter's own directionality: no mirrored stylesheet, no second layout. Icons that must not flip are pinned explicitly (§10). يُعالَج بيد Flutter نفسها عبر الاتجاهية: لا ورقة أنماط معكوسة، ولا تخطيط ثانٍ. والرموز التي لا يجوز قلبها تُثبَّت صراحة (§10).
Skeleton / shimmer Placeholder trees that mirror the real layout section for section, swept by a ShimmerScope (§9, §15.9). Named *_skeleton.dart. أشجار بديلة تعكس التخطيط الحقيقي قسمًا قسمًا، ويمسحها ShimmerScope (§9، §15.9). وتُسمّى *_skeleton.dart.

Testingالاختبار

Termالمدخل In this project it meansمعناه في هذا المشروع
Page object The Java layer of the Appium suite: LoginPage and HomePage hold the locators, BaseTest holds the lifecycle, and a test class adds steps only (§13). طبقة Java في مجموعة Appium: يحمل LoginPage وHomePage العناوين، ويحمل BaseTest دورة الحياة، ولا تضيف صنف الاختبار إلا الخطوات (§13).
resource-id The Android attribute an Appium XPath addresses. Flutter publishes it from Semantics(identifier:), which is why SemanticId exists (§12, §13, §17.6). سمة أندرويد التي يخاطبها XPath في Appium. وينشرها Flutter من Semantics(identifier:)، وهذا وُجد لأجله SemanticId (§12، §13، §17.6).
explicitChildNodes Set true because Flutter otherwise merges a card's labels into one node and the Add-to-Cart button — with its identifier — disappears from the tree (§12, §17.6). مُفعَّل لأن Flutter يدمج تسميات البطاقة في عقدة واحدة وإلا ويختفي زر الإضافة — ومعرّفه معه — من الشجرة (§12، §17.6).
mocktail / blocTest The unit layer: abstract repositories are mocked, GetIt is stubbed, and seven blocTest cases drive CartBloc (§13). طبقة الوحدات: تُحاكى المستودعات المجرّدة ويُزيف GetIt، وتقاد CartBloc بسبع حالات blocTest (§13).
Manual QA workbook 51 generated cases, 17 executed on the phone, 34 left blocked with the reason recorded — not silently passed (§13). 51 حالة مولَّدة، نُفِّذ منها 17 على الهاتف، وتُركت 34 محجوبة بسبب مسجَّل — لا نجحت بصمت (§13).
Defect id SB-1xx The workbook's own numbering; SB-111 is the case that would have shipped, SB-119 the credential finding (§13). ترقيم دفتر الاختبار اليدوي؛ فـ SB-111 هي الحالة التي كانت ستخرج، وSB-119 ملاحظة البيانات (§13).
Golden test Absent, and listed as a gap in §13 rather than described as a feature: pixel snapshots would need a CI runner this project does not have. غير موجودة، ومذكورة كفجوة في §13 لا كميزة: لالتقاطات البيكسل تحتاج مشغّل CI لا يملكه هذا المشروع.

Build and platformالبناء والمنصّة

Termالمدخل In this project it meansمعناه في هذا المشروع
Android-only The product is an APK. ios/ exists because flutter create wrote it and is reverted when the generator churns it (§14). المنتج APK. ويوجد ios/ لأن flutter create كتبه، ويُرجَع حين يُغيّره المولّد (§14).
1.0.0+3 Version name plus build number, written once in pubspec.yaml and fed to Gradle through flutter.versionName/versionCode (§14, §17.7). اسم الإصدار ورقم البناء، مكتوبان مرة في pubspec.yaml ويغذّيان Gradle عبر flutter.versionName وversionCode (§14، §17.7).
compileSdk 36 · targetSdk 35 · minSdk 24 Compile against the newest platform, promise Android 15 behaviour, install from Android 7. Each number's reason is in §14. بناء ضد أحدث منصّة، وسلوك أندرويد 15 الموعود، وتركيب من أندرويد 7. وسبب كل رقم في §14.
R8 / minification On for release: 197 MB debug APK to 63 MB release, with a handful of -keep rules for the map and auth plugins (§14). مفعّل في الإصدار: من APK debug بـ197 ميغابايت إلى release بـ63، مع عدة قواعد -keep لإضافتَي الخريطة والمصادقة (§14).
Debug signing The release APK is signed with the debug key — honest for a course artefact, and the reason §14 says it must not go to Play. APK الإصدار موقّع بمفتاح التنقيح — وهذا صادق لأجل مقرر، وهو سبب قول §14 إنه لا يُرسل إلى Play.
Offline fallback allowOfflineFirebaseFallback: when Firebase cannot be reached the app answers from the on-device store instead of failing (§7, §17.1). allowOfflineFirebaseFallback: عند تعذر الوصول إلى Firebase تجيب الطبقة من متجر الجهاز بدل الفشل (§7، §17.1).
Vendor map Five hardcoded street-food vendors in five areas, fed to Google Maps. The blank-map blocker is a cloud-key enablement problem, not app code (§7, §14). خمسة بائعي شارع ثابتين في خمس مناطق تُعطى لخرائط Google. والعائق — الخريطة الفارغة — مسألة تفعيل مفتاح سحابي لا كود التطبيق (§7، §14).
Demo account yasmine@streetbite.app / StreetBite123, committed on purpose as the Appium suite's login and the offline store's seed (§13, §17.1). yasmine@streetbite.app / StreetBite123، مُودَع عن قصد لأنه دخول مجموعة Appium وجرعة المتجر المحلي (§13، §17.1).
