15 · Every file in lib/15 · كل ملف في lib/

This is the complete mechanical inventory: 158 hand-written Dart files, 15,491 lines, plus the three generated localisation files listed separately in §15.5. Each row is the path, the exact line count, and one sentence saying what the file is for.

The descriptions are generated from the source, not written from memory: each one is the first line of that file's own dartdoc, with hand-written corrections for the 25 rows the extraction truncated or which described a neighbouring class in the same file. The Arabic line is the matching gloss. Where this table and a source file disagree, the source wins — and the disagreement is a documentation bug worth reporting.

هذا الجرد الميكانيكي الكامل: 158 ملف Dart مكتوبة يدويًا، 15,491 سطرًا، إضافة إلى ثلاثة ملفات ترجمة مولَّدة تُسرد على حدة في §15.5. يعطي كل سطر المسار، وعدد الأسطر الفعلي، وجملة واحدة تقول وظيفة الملف.

الأوصاف مولَّدة من المصدر لا من الحفظ: كل وصف هو أول سطر من توثيق dartdoc الخاص بالملف نفسه، مع تصحيحات مكتوبة يدويًا لخمسة وعشرين سطرًا اقتُطع جردُه أو وصف صنفًا مجاورًا في الملف نفسه. والسطر العربي مقابلُه. وحيث يخالف هذا الجدول ملف المصدر، يفوز المصدر — وتلك المخالفة خطأ توثيق يستحق الإبلاغ.

15.1 · The three files at the top15.1 · الملفات الثلاثة في الجذر

These are the only files outside a layer folder. main.dart boots, app.dart wires the cubits and the MaterialApp, injection.dart builds the object graph — read them in that order and the rest of the tree explains itself.

هذه هي الملفات الثلاثة الوحيدة خارج مجلدات الطبقات. يقلع main.dart التطبيق، ويوصل app.dart حالات Cubit بـ MaterialApp، ويبني injection.dart رسم الكائنات — اقرأها بهذا الترتيب فتشرح بقية الشجرة نفسها.
