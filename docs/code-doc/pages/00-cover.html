StreetBite · Graduation Capstone · 2026

StreetBite — the complete code & app documentation

Hyperlocal food discovery and ordering, built as a graduation capstone: a live vendor map, a real menu API (TheMealDB), cart and checkout, orders, favourites and fingerprint sign-in — in English and Arabic, light and dark.

Part I explains the ideas the code is built on — architecture, dependency injection, state, errors, data, domain, theme, localisation, security, navigation, testing and the build. Part II is the reference extracted mechanically from the source tree: every file under lib/, every type, every key.

  • Eighteen sections across two parts, plus this cover and a closing project summary
  • English and Arabic side by side — the EN / AR / Both choice is remembered on every page
  • Generated from the source, not hand-copied (_audit/build_site.py)

ستريت بايت · مشروع تخرّج · ٢٠٢٦

ستريت بايت — التوثيق الكامل للكود والتطبيق

تطبيق لاكتشاف الطعام المحلي وطلبه، بُني كمشروع تخرّج: خريطة حيّة للبائعين، وقائمة طعام من واجهة برمجية حقيقية (TheMealDB)، وسلّة وإتمام طلب، وطلبات ومفضّلات، ودخول ببصمة الإصبع — بالإنجليزية والعربية، ومظهر فاتح وداكن.

الجزء الأول يشرح الأفكار التي بُني عليها الكود: المعمارية، وحقن الاعتماديات، والحالة، والأخطاء، والبيانات، والمجال، والسمة، والتوطين، والحماية، والتنقّل، والاختبار، والبناء. الجزء الثاني مرجع مُستخرَج آليًا من شجرة المصدر: كل ملف تحت lib/ وكل صنف وكل مفتاح.

  • ثمانية عشر قسمًا في جزأين، مع هذا الغلاف وملخّص المشروع الختامي
  • الإنجليزية والعربية جنبًا إلى جنب — ويُتذكَّر اختيار EN/عربي/كلاهما في كل صفحة
  • مولَّد من المصدر لا منسوخ يدويًا (_audit/build_site.py)
