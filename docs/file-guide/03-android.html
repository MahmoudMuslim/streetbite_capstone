03 android/ — how a Flutter app becomes an APK‏android/ — كيف يصير تطبيق Flutter ملف APK

Flutter compiles the Dart code; Gradle assembles the Android artefact. This folder is where the capstone stops being "a Flutter project" and becomes an installable app: two Kotlin-script build files, a manifest that states every permission, one Activity class, the launcher icon resources and a signing block.

Four decisions here are worth defending on their own: the Maps key is injected from a git-ignored key.properties; the Google Services plugin is applied only if google-services.json exists; MainActivity extends FlutterFragmentActivity because local_auth needs a FragmentManager; and Kotlin incremental compilation is switched off to stop Windows file locks from breaking the build.

‏Flutter يصنع شيفرة Dart، وGradle يركّب ناتج Android. هنا يصبح مشروع التخرّج ليس "مشروع Flutter" فحسب بل تطبيقًا قابلًا للتثبيت: ملفا بناء بلغة Kotlin النصية، وبيان يعلن كل الأذونات، وصف Activity واحد، وموارد أيقونة التشغيل، وكتلة توقيع.

أربعة قرارات هنا تصلح للدفاع عنها منفردة: مفتاح Maps يُحقن من key.properties مستثنًى من Git؛ وإضافة Google Services تُطبَّق فقط إذا وُجد google-services.json؛ وMainActivity يرث FlutterFragmentActivity لأن local_auth يحتاج مدير مقاطع؛ وتصنيف Kotlin التدريزي مطفأ حتى لا تكسر أقفال الملفات في Windows البناء.

streetbite_capstone/android/settings.gradle.ktscfg

The Gradle entry point: which plugins exist and where the Flutter SDK is.

نقطة دخول Gradle: ما الإضافات الموجودة وأين يوجد Flutter SDK.

Has
pluginManagement reading flutter.sdk out of local.properties, includeBuild("$flutterSdkPath/packages/flutter_tools/gradle"), three repositories, and the plugin block: dev.flutter.flutter-plugin-loader 1.0.0, com.android.application 9.1.0, com.google.gms.google-services 4.3.15, org.jetbrains.kotlin.android 2.4.0, then include(":app").
يحتوي
pluginManagement يقرأ flutter.sdk من local.properties، وincludeBuild("$flutterSdkPath/packages/flutter_tools/gradle")، ومستودعات ثلاثة، وكتلة الإضافات: dev.flutter.flutter-plugin-loader 1.0.0 وcom.android.application 9.1.0 وcom.google.gms.google-services 4.3.15 وorg.jetbrains.kotlin.android 2.4.0 ثم include(":app").
Does
Runs before any compilation: it locates the Flutter Gradle plugin (which is not on any public repository) and pins the Android/Kotlin/Firebase plugin versions so every machine resolves the same ones. The require(flutterSdkPath != null) line converts a missing SDK into one readable error instead of a stack trace.
يفعل
تعمل قبل أي ترجمة: فتحدّد موقع إضافة Flutter في Gradle (وهي ليست على أي مستودع عام)، وتثبّت إصدارات إضافات Android وKotlin وFirebase لتتطابق كل الأجهزة. وسطر require(flutterSdkPath != null) يحوّل SDK مفقود إلى رسالة مقروءة بدل أثر مكدّس.
Needs
android/local.properties (machine-local, ignored) and the Flutter SDK it points at.
يحتاج
android/local.properties (محلي للآلة ومستثنًى) وFlutter SDK الذي يشير إليه.
Try it
Delete the flutter.sdk line from local.properties and run flutter build apk. Read the message: that is the guard doing its job.
جرّب
احذف سطر flutter.sdk من local.properties ونفّذ flutter build apk واقرأ الرسالة: ذلك هو الحاجز يعمل.

streetbite_capstone/android/gradle.propertiescfg

Gradle JVM and build-behaviour switches, with the Windows workarounds documented.

مفاتيح JVM وسلوك Gradle، مع حلول مشاكل Windows موثّقة.

Has
org.gradle.jvmargs=-Xmx8G and friends, android.useAndroidX=true, android.newDsl=false, android.builtInKotlin=false, kotlin.incremental=false, kotlin.compiler.execution.strategy=in-process, android.nonTransitiveRClass=true, android.nonFinalResIds=true.
يحتوي
org.gradle.jvmargs=-Xmx8G وما شابهها، وandroid.useAndroidX=true وandroid.newDsl=false وandroid.builtInKotlin=false وkotlin.incremental=false وkotlin.compiler.execution.strategy=in-process وandroid.nonTransitiveRClass=true وandroid.nonFinalResIds=true.
Does
Fixes a real, reproducible failure: on Windows the Kotlin incremental caches (.tab files) cannot be closed when antivirus or the Search index holds a handle, and the build dies with "Could not close incremental caches". The comment names the trade: a few extra seconds per plugin module.
يفعل
يصلح عطلًا حقيقيًا قابلًا للتكرار: في Windows لا يمكن إغلاق ذاكرات Kotlin التدريزية (.tab) حين يمسك مضاد الفيروسات أو فهرس البحث مقبضًا عليها، فيموت البناء بـ «Could not close incremental caches». والتعليق يسمّي المقايضة: ثوانٍ إضافية لكل وحدة إضافة.
Needs
Read by the Gradle daemon at start-up.
يحتاج
يقرؤها خادم Gradle عند الإقلاع.
Try it
Set kotlin.incremental=true and rebuild twice on a Windows machine with Defender scanning the folder. You will meet the original bug.
جرّب
اجعل kotlin.incremental=true وأعد البناء مرتين على Windows مع فحص Defender للمجلد؛ ستقابل العطل الأصلي.
streetbite_capstone/android/app/build.gradle.ktscfg

The module that produces the APK: SDK levels, application id, key injection and signing.

الوحدة التي تنتج APK: مستويات SDK ومعرف التطبيق وحقن المفتاح والتوقيع.

Has
namespace/applicationId = com.example.streetbite_capstone, compileSdk = 36, minSdk = 24, targetSdk = 35, Java/Kotlin 17, manifestPlaceholders["MAPS_API_KEY"] read from key.properties, a google-services apply wrapped in if (file(...).exists()), and a release block with debug signing, isMinifyEnabled, isShrinkResources and ProGuard files.
يحتوي
namespace وapplicationId = com.example.streetbite_capstone وcompileSdk = 36 وminSdk = 24 وtargetSdk = 35 وJava/Kotlin 17، وmanifestPlaceholders["MAPS_API_KEY"] من key.properties، وapply google-services داخل if (file(...).exists())، وكتلة الإصدار بتوقيع التصحيح وisMinifyEnabled وisShrinkResources وملفات ProGuard.
Does
Balances three constraints at once: bundled plugins (maps, image_picker, local_auth) need compileSdk 36; local_auth needs minSdk 23+ and 24 is the practical Play floor; and a fresh clone must still build without Firebase, hence the conditional plugin apply.
يفعل
يوازن ثلاثة قيود معًا: الإضافات المضمّنة (maps وimage_picker وlocal_auth) تريد compileSdk 36؛ وlocal_auth تريد minSdk 23 فأكثر و24 هو الحد العملي لـ Play؛ والاستنساخ الجديد يجب أن يُبنى بلا Firebase — ومن هنا التطبيق الشرطي للإضافة.
Needs
key.properties (optional, ignored), google-services.json (optional, ignored), and the Flutter Gradle plugin for flutter.versionCode/versionName.
يحتاج
key.properties (اختياري ومستثنًى) وgoogle-services.json (اختياري ومستثنًى) وإضافة Flutter في Gradle لأجل flutter.versionCode/versionName.
Try it
Comment out the if (file("google-services.json").exists()) guard and run flutter build apk on a checkout without that file. The hard failure is exactly why the guard exists.
جرّب
عطّل السطر if (file("google-services.json").exists()) مؤقتًا ونفّذ flutter build apk على نسخة بلا ذلك الملف. الفشل الصارم هو بعينه سبب وجود الحاجز.
streetbite_capstone/android/app/src/main/AndroidManifest.xmlcfg

The app's legal and technical declaration to Android.

الإعلان القانوني والتقني للتطبيق أمام Android.

Has
Seven uses-permission entries (INTERNET, ACCESS_NETWORK_STATE, ACCESS_COARSE_LOCATION, ACCESS_FINE_LOCATION, USE_BIOMETRIC, READ_MEDIA_IMAGES, READ_EXTERNAL_STORAGE with maxSdkVersion="32"), a uses-feature for the fingerprint sensor marked required="false", the .MainActivity declaration with singleTop and a long configChanges list, a launcher intent filter, a deep link on the streetbite scheme, the ${MAPS_API_KEY} metadata and the flutterEmbedding=2 metadata.
يحتوي
سبعة مدخلات uses-permission (‏INTERNET وACCESS_NETWORK_STATE وACCESS_COARSE_LOCATION وACCESS_FINE_LOCATION وUSE_BIOMETRIC وREAD_MEDIA_IMAGES وREAD_EXTERNAL_STORAGE مع maxSdkVersion="32")، وuses-feature لمستشعر البصمة بـ required="false"، وإعلان .MainActivity بـ singleTop وقائمة configChanges طويلة، ومرشاح نية للمُشغِّل، وارتباط عميق على مخطط streetbite، وبيانات ${MAPS_API_KEY} الوصفية وflutterEmbedding=2.
Does
Grants each feature exactly what it needs and nothing more: coarse location only because the map shows a distance hint, biometrics as a nice-to-have so devices without a sensor can still install the app, and the legacy storage permission capped at API 32 where READ_MEDIA_IMAGES takes over.
يفعل
يمنح كل ميزة ما تحتاجه بالضبط ولا يزيد: الموقع الخشن فقط لأن الخريطة تبدي مسافة تقريبية، والبصمة كمزية لا شرط حتى يُثبَّت التطبيق على جهاز بلا مستشعر، وإذن التخزين القديم مقيّد بـ API 32 حيث يحل محلّه READ_MEDIA_IMAGES.
Needs
The Gradle placeholder MAPS_API_KEY; an empty value still builds — the map just renders grey.
يحتاج
الوسيط MAPS_API_KEY في Gradle؛ وقيمة فارغة تسمح بالبناء أيضًا — غير أن الخريطة تظهر رمادية.
Try it
Set the deep link to work: run adb shell am start -a android.intent.action.VIEW -d "streetbite://qa/reset" and watch the app relaunch. That is how the Appium suite gets a clean state.
جرّب
جرّب الارتباط العميق: نفّذ adb shell am start -a android.intent.action.VIEW -d "streetbite://qa/reset" وشاهد إقلاع التطبيق. هكذا تحصل حزمة Appium على حالة نظيفة.
streetbite_capstone/android/app/src/main/kotlin/com/example/streetbite_capstone/MainActivity.ktnative

The only hand-written Kotlin in the project: six lines that make biometrics work.

الشيفرة الوحيدة المكتوبة يدويًا بلغة Kotlin في المشروع: ستة أسطر تجعل البصمة تعمل.

يحتاج
io.flutter.embedding.android.FlutterFragmentActivity من محرك Android في Flutter.
Try it
Change the superclass to FlutterActivity, rebuild, and tap the fingerprint button. The failure is immediate and silent — the best possible demo of why native glue matters.
جرّب
غيّر الصنف الأب إلى FlutterActivity وأعد البناء ثم اضغط زر البصمة. الفشل فوري وصامت — أفضل عرض ممكن لأهمية اللحمة الأصلية.

values/styles.xml + values-night/styles.xml (LaunchTheme/NormalTheme), values/colors.xml (ic_launcher_background = #00C16A), drawable/launch_background.xml and drawable-v21/, mipmap-anydpi-v26/ic_launcher.xml (adaptive icon with foreground + monochrome insets), and mipmap-*dpi / drawable-*dpi PNGs from mdpi to xxxhdpi.
يحتوي
values/styles.xml وvalues-night/styles.xml (LaunchTheme/NormalTheme) وvalues/colors.xml (ic_launcher_background = #00C16A) وdrawable/launch_background.xml وdrawable-v21/ وmipmap-anydpi-v26/ic_launcher.xml (أيقونة تكيّفية بهامش أمامي وأحاد)، وPNGات mipmap-*dpi وdrawable-*dpi من mdpi إلى xxxhdpi.
Does
Draws the native window background before Flutter paints its first frame (so no white flash), and lets the launcher mask the icon correctly — including Android 13's monochrome themed icon.
يفعل
يرسم خلفية النافذة الأصلية قبل أن ترسم Flutter إطارها الأول (فلا وميض أبيض)، ويسمح للمشغّل بقصّ الأيقونة صحيحًا — بما فيها الأيقونة أحادية اللون في Android 13.
Needs
The PNGs are produced by streetbite_capstone/scripts/make_launcher_icons.py and flutter_launcher_icons in pubspec.yaml.
يحتاج
PNGات ينتجها streetbite_capstone/scripts/make_launcher_icons.py وflutter_launcher_icons في pubspec.yaml.
Try it
Change ic_launcher_background to #FFB020, rebuild, and see the adaptive icon change on the home screen without touching a single PNG.
جرّب
غيّر ic_launcher_background إلى #FFB020 وأعد البناء وشاهد الأيقونة تتغير دون لمس أي PNG.
streetbite_capstone/android/app/src/main/java/io/flutter/plugins/GeneratedPluginRegistrant.javanative

Tool-generated glue that registers every native plugin with the engine.

لحمة مولَّدة تسجّل كل إضافة أصلية في المحرك.

Has
A registerWith method listing firebase_core, firebase_auth, cloud_firestore, google_maps_flutter, image_picker, local_auth_android, device_info_plus, shared_preferences.
يحتوي
دالة registerWith تعدّد firebase_core وfirebase_auth وcloud_firestore وgoogle_maps_flutter وimage_picker وlocal_auth_android وdevice_info_plus وshared_preferences.
Does
Written by the Flutter tool on every build from .flutter-plugins-dependencies; hence it is git-ignored, and deleting it costs nothing.
يفعل
تكتبها أداة Flutter عند كل بناء من .flutter-plugins-dependencies؛ ولذا فهو مستثنًى من Git، وحذفه لا يكلّف شيئًا.
Needs
The plugin set declared in pubspec.yaml.
يحتاج
مجموعة الإضافات المعلنة في pubspec.yaml.
Try it
Run flutter pub get and diff the file. It changes exactly when the plugin list does — which is the point of not committing generated code.
جرّب
نفّذ flutter pub get وقارن الملف. يتغيّر حين تتغيّر قائمة الإضافات فقط — وهذا هو مبرر عدم رفع الشيفرة المولَّدة.

How this document was made. Written against commit 07b200f. Every card was produced by reading the file it describes; the line counts, declaration names and import lists are extracted from the source tree by _audit/imports.py, and _audit/build_guide.py refuses to build if a card points at a Dart file that no longer exists. Nothing here is remembered from a previous draft.

Companion documents. docs/code-doc/index.html explains the concepts (architecture, state, errors, security) layer by layer; this guide answers the other question — what is each file for. docs/StreetBite_Capstone_Report_EN-AR.pptx is the slide deck for the defence itself.

Language. Both columns are on by default; the sidebar switches to English or Arabic only. Paths, identifiers and code are never translated, because Either<Failure, List<MealEntity>> reads the same in either language.
