05 assets/ and scripts/ — binary art and the tools that make it‏assets/ وscripts/ — فنّ ثنائي وأدواته

Only three images ship inside the app, and one empty folder is the more interesting fact: every other pixel is either painted in code (streetbite_logo.dart, " "glass_aurora.dart) or fetched from the network (TheMealDB photos). The scripts/ " "folder holds the Python that keeps that claim true — regenerating icons and auditing translation keys.

ثلاثة صور فقط تُرفق بالتطبيق، والحقيقة الأشمل في مجلد فارغ: كل بكسل آخر إما مرسوم بالشيفرة "(streetbite_logo.dart وglass_aurora.dart) أو مُنزَّل من الشبكة (صور TheMealDB). " "ومجلد scripts/ يحفظ Python الذي يبقي هذا الكلام صحيحًا — إعادة توليد الأيقونات ومراجعة مفاتيح " "الترجمة.

streetbite_capstone/assets/icon/ (3 PNG)art

The launcher-icon masters: full tile, adaptive foreground and monochrome layer.

أصول أيقونة التشغيل: البلاطة الكاملة والطبقة الأمامية التكيّفية والطبقة أحادية اللون.

Has
launcher_icon.png (1024px master), launcher_icon_foreground.png and launcher_icon_monochrome.png.
يحتوي
launcher_icon.png (أصل 1024 بكسل) وlauncher_icon_foreground.png وlauncher_icon_monochrome.png.
Does
Feed flutter_launcher_icons, which expands them into every mipmap/density folder under android/app/src/main/res/. They sit outside assets/images/ on purpose: that folder is declared in pubspec.yaml and would ship the 1024px masters inside the APK.
يفعل
تغذّي flutter_launcher_icons التي تفسّخها إلى كل مجلد mipmap/كثافة تحت android/app/src/main/res/. وهي خارج assets/images/ عن قصد: ذلك المجلد معلن في pubspec.yaml وكان سيرفع الأصول الكبيرة داخل APK.
Needs
scripts/make_launcher_icons.py to regenerate them.
يحتاج
scripts/make_launcher_icons.py لإعادة توليدها.
Try it
Run python scripts/make_launcher_icons.py then dart run flutter_launcher_icons and watch fourteen PNGs change across six density folders.
جرّب
نفّذ python scripts/make_launcher_icons.py ثم dart run flutter_launcher_icons وشاهد أربعة عشر PNG تتغيّر في ستة مجلدات كثافة.
streetbite_capstone/assets/images/.gitkeepart

An empty declared asset folder — the placeholder that makes pubspec.yaml valid.

مجلد موارد مُعلَن لكنه فارغ — الحارس الذي يجعل pubspec.yaml صالحًا.

Has
A zero-byte file, nothing else.
يحتوي
ملف بصفر بايت ولا شيء غيره.
Does
Git cannot track an empty directory, and flutter fails the build when an asset path listed in pubspec.yaml does not exist. So the folder is kept alive by a sentinel. It also states, in the loudest way possible, that the app ships no bundled photography: the food pictures come from the API and are cached by cached_network_image.
يفعل
لذا يُبقي المجلدَ حارسًا. وهو أيضًا يعلن بأوضح طريقة أن التطبيق لا يحمل صورًا مرفقة: صور الطعام من الواجهة البرمجية وتُخزَّن محليًا بواسطة cached_network_image.
Needs
The assets: block in pubspec.yaml.
يحتاج
كتلة assets: في pubspec.yaml.
Try it
Delete the file and run flutter build apk. The error mentions the missing asset folder, not a missing image — a build failure worth having seen once.
جرّب
احذف الملف ونفّذ flutter build apk. الخطأ يذكر مجلد موارد مفقود لا صورة مفقودة — عطل بناء يستحق أن تراه مرة.
streetbite_capstone/scripts/make_launcher_icons.pytool

Redraws the brand mark as raster icons instead of screenshotting the widget.

يعيد رسم علامة التطبيق كنقاط صورة بدل تصوير المعيار.

Has
133 lines: canvas maths, the bowl-and-steam geometry, the green background fill and the three output PNGs. A long docstring explains why the launcher version is not a copy of the in-app drawing.
يحتوي
١٣٣ سطرًا: حساب اللوحة، وهندسة الوعاء والبخار، وتعبئة الخلفية الخضراء، وثلاثة PNGات مخرَجة. وتعليق طويل يشرح لماذا نسخة المشغّل ليست نسخًا من الرسم داخل التطبيق.
Does
Generates assets/icon/*.png from code so the mark stays pixel-exact and regenerates whenever the brand changes. The comment records an actual legibility finding: the thin stroked arc that works on a 96dp white tile reads as a smiley with three exclamation marks on a 48dp green square, so the launcher version uses a filled silhouette with an overhanging lip.
يفعل
يولّد assets/icon/*.png من الشيفرة فتبقى العلامة مطابقة بالبكسل وتتجدد كلما تغيّرت العلامة. ويوثّق التعليق ملاحظة مقروئية حقيقية: القوس الرفيع المرسوم بخط يعمل على بلاطة بيضاء 96dp يبدو وجهًا مبتسمًا وثلاثة علامات تعجب على مربع أخضر 48dp، لذا استُعمل في المشغّل ظلّ مصمت بحافة زائدة.
Needs
Python with an image library (Pillow); output is consumed by flutter_launcher_icons.
يحتاج
Python مع مكتبة صور (Pillow)؛ والمخرج تستهلكه flutter_launcher_icons.
Try it
Change the fill colour to #FFB020, re-run it, re-run the icon plugin and look at the launcher. Design-to-build in three commands.
جرّب
غيّر لون التعبئة إلى #FFB020 وأعد السكربت وأعد إضافة الأيقونة وانظر إلى المشغّل. من التصميم إلى البناء بثلاثة أوامر.
streetbite_capstone/scripts/check_unused_arb.pytool

Proves the brief's rule: no dead translation keys in the submission.

يُثبت شرط التكليف: لا مفاتيح ترجمة ميتة في التسليم.

Has
45 lines that read both ARB files, scan every Dart source for a quoted 'key' or a l10n.key getter, and print the keys nothing references.
يحتوي
٤٥ سطرًا تقرأ ملفي ARB وتمسح كل مصادر Dart بحثًا عن 'key' بالاقتباس أو عن l10n.key، ثم تطبع المفاتيح التي لا يشير إليها شيء.
Does
Turns "we removed unused entries" into a reproducible check the examiner can run. A key counts as used in either of two forms, so neither the trKey style nor the getter style is missed.
يفعل
يحوّل عبارة «حذفنا الداخل غير المستخدم» إلى فحص قابل للتكرار يستطع المناقش تشغيله. والمفتاح يُعدّ مستخدمًا بإحدى الصيغتين فلا تفلت صيغة trKey ولا صيغة الجِتّر.
Needs
lib/l10n/app_en.arb, lib/l10n/app_ar.arb and all of lib/.
يحتاج
lib/l10n/app_en.arb وlib/l10n/app_ar.arb وكل lib/.
Try it
Run it from streetbite_capstone/: python scripts/check_unused_arb.py should print nothing. Add a key you never use, re-run, and see it reported.
جرّب
شغّله من streetbite_capstone/: python scripts/check_unused_arb.py لا يجب أن يطبع شيئًا. أضف مفتاحًا لا تستخدمه وأعد التشغيل لترى اسمه مطبوعًا.
streetbite_capstone/scripts/prune_arb.pytool

Deletes unused keys from both ARB files at once, so the locales cannot drift.

يحذف المفاتيح غير المستخدمة من ملفي ARB معًا حتى لا تتباعد اللغتان.

Has
73 lines: the same usage scan, then JSON surgery on both files preserving key order, and a report of what was removed.
يحتوي
٧٣ سطرًا: مسح الاستخدام نفسه ثم جراحة JSON على الملفين مع حفظ ترتيب المفاتيح، وتقرير بالحذف.
Does
Acts on the finding of check_unused_arb.py. Removing a key from app_en.arb alone would make flutter gen-l10n fail or emit a missing-translation hole in Arabic; this edits both in one pass.
يفعل
ينفّذ نتيجة check_unused_arb.py. وحذف مفتاح من app_en.arb وحدها يجعل flutter gen-l10n يفشل أو يثقب الترجمة العربية؛ وهذه الأداة تعدّل الملفين في مرّة واحدة.
Needs
The two ARB files; after running it, re-run flutter gen-l10n.
يحتاج
ملفا ARB؛ وبعدها أعد flutter gen-l10n.
Try it
Dry-run it on a copy of the ARB files, diff the result with Git, then delete the copy. That is the safe workflow for any generator.
جرّب
جرّبه على نسخة من ملفي ARB وقارن الناتج بـ Git ثم احذف النسخة. ذلك هو المسار الآمن لأي مولّد.
streetbite_capstone/_audit/tool

Local device-audit scratch: screenshots and uiautomator dumps taken while debugging the UI.

تفرغات تدقيق الجهاز المحلي: لقطات وتفرغات uiautomator أثناء تصحيح الواجهة.

Has
PNGs of the Arabic page, biometric gate, login and settings states, XML layout dumps (home_tree.xml, ar.xml, l.xml, p.xml) and map_logcat.txt.
يحتوي
لقطات PNG للصفحة العربية وبوابة البصمة وتسجيل الدخول وحالات الإعدادات، وتفرغات XML للتخطيط (home_tree.xml وar.xml وl.xml وp.xml) وmap_logcat.txt.
Does
Evidence, not source. It records what a screen actually looked like at a moment in time — which is how a layout bug gets proven rather than argued about.
يفعل
أدلّة لا مصادر. تسجّل كيف بدت الشاشة فعلًا في لحظة معينة — وبها يُبرهن على خطأ تخطيط بدل الجدل حوله.
Needs
adb exec-out uiautomator dump and adb exec-out screencap.
يحتاج
adb exec-out uiautomator dump وadb exec-out screencap.
Try it
Open streetbite_capstone/_audit/ar.xml and find a node whose bounds disagree with ar_page.png. That is the debugging loop the folder exists for.
جرّب
افتح streetbite_capstone/_audit/ar.xml وجد عقدة لا تتفق حدودها مع ar_page.png. ذلك هي حلقة التصحيح التي وُجد المجلد لأجلها.

How this document was made. Written against commit 07b200f. Every card was produced by reading the file it describes; the line counts, declaration names and import lists are extracted from the source tree by _audit/imports.py, and _audit/build_guide.py refuses to build if a card points at a Dart file that no longer exists. Nothing here is remembered from a previous draft.

Companion documents. docs/code-doc/index.html explains the concepts (architecture, state, errors, security) layer by layer; this guide answers the other question — what is each file for. docs/StreetBite_Capstone_Report_EN-AR.pptx is the slide deck for the defence itself.

Language. Both columns are on by default; the sidebar switches to English or Arabic only. Paths, identifiers and code are never translated, because Either<Failure, List<MealEntity>> reads the same in either language.

كيف صُنعت هذه الوثيقة. كُتبت عند الالتزام 07b200f. وكل بطاقة نُقلت بعد قراءة الملف الموصوف؛ وأعداد الأسطر وأسماء التصريحات وقوائم الاستيراد تُستخرج من شجرة المصدر بواسطة _audit/imports.py، و_audit/build_guide.py يرفض البناء إذا أشارت بطاقة إلى ملف Dart لم يعد موجودًا. ولا شيء هنا من الاستذكار.

الوثائق المكمّلة. يشرح docs/code-doc/index.html المفاهيم (المعمارية، الحالة، الأخطاء، الحماية) طبقة طبقة؛ أما هذا الدليل فيجيب عن السؤال الآخر: ما وظيفة كل ملف. وملف docs/StreetBite_Capstone_Report_EN-AR.pptx هو العرض التقديمي للمناقشة.

اللغة. العمودان ظاهران افتراضيًا، ويحوّلهما الشريط الجانبي إلى الإنجليزية أو العربية وحدها. ولا تُترجَم المسارات والمعرّفات والشفرة أبدًا، لأن Either<Failure, List<MealEntity>> تُقرأ بالشكل نفسه في اللغتين.
