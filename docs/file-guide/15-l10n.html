15 ‏lib/l10n — two catalogues, three generated files, 178 keys‏lib/l10n — فهرسان يدويان وثلاثة ملفات مولّدة و١٧٨ مفتاحًا

Five files: two catalogues written by hand and three produced by flutter gen-l10n. Together they are the only place in lib/ where a literal user-facing string is allowed to live. Every widget reaches its text through AppLocalizations, so the 178 keys here are the whole vocabulary of the application in each language — nothing more.

The English file is a schema, not merely English prose: it decides which members exist, how many arguments each one takes, what type those arguments have, and in which order the generated class lists them. The Arabic file is 178 values and nothing else — not one metadata block — which works perfectly and also means the only brief an Arabic translator can read is the English file itself.

Nothing in this folder is hand-edited after generation, and that claim is checkable rather than asserted: run the generator on a clean checkout and git diff stays empty. The 2387 generated lines are committed on purpose, because l10n.yaml points output-dir inside lib/ so that the exact strings shipped in the APK are visible in review.

خمسة ملفات: فهرسان كُتبا يدويًا وثلاثة أنتجها flutter gen-l10n. وهي المكان الوحيد في lib/ الذي يُسمح فيه بنصٍّ حرفي يراه المستخدم. فكل معيار يصل إلى نصه عبر AppLocalizations، إذن المفاتيح الـ١٧٨ هنا هي مفردات التطبيق كاملةً في كل لغة، لا أكثر.

الملف الإنجليزي مخطّط وليس مجرد نصوص إنجليزية: هو الذي يقرّر أيّ الأعضاء يوجد، وكم وسيطًا يأخذ كل منها، وما نوع تلك الوسائط، وبأي ترتيب يعدّها الصنف المولّد. أما الملف العربي فمئة وثمانية وسبعون قيمة ولا شيء غيرها — لا كتلة بيانات وصفية واحدة — وهذا يعمل تمامًا، ويجعل الملف الإنجليزي هو الوصف الوحيد الذي يقرأه المترجم العربي.

لا يُعدَّل شيء في هذا المجلد يدويًا بعد التوليد، وهذه دعوى قابلة للتحقق لا مجرد قول: شغّل المولّد على نسخة نظيفة وسيبقى git diff فارغًا. والأسطر المولّدة البالغ عددها ٢٣٨٧ مُلتزَمة في المستودع عن عمد، لأن l10n.yaml يوجّه output-dir إلى داخل lib/ فتظهر النصوص التي تخرج في APK أمام المراجعة.

streetbite_capstone/lib/l10n/app_en.arbl10n

The template catalogue: 178 English messages, the placeholder contract, and the only literal strings in the project.

الفهرس الأم: ١٧٨ رسالة إنجليزية، وعقد الوسائط، والنصوص الحرفية الوحيدة في المشروع.

Has
178 message keys, @@locale: en, and 16 @ blocks besides it — 13 declare placeholders and 5 carry a translator description. One ICU plural (orderItemsCount with =1 and other). One doubled apostrophe (Don''t have an account?).
يحتوي
١٧٨ مفتاح رسالة، و@@locale: en، وست عشرة كتلة @ غيرها — ثلاثة عشر يعلن وسائط وخمس تحمل description للمترجم. وصيغة جمع ICU واحدة هي orderItemsCount بفرعي =1 وother. وفاصلة عليا مضعّفة واحدة في Don''t have an account?.
Does
Because l10n.yaml names it template-arb-file, this file alone decides the generated API: every key becomes a member, every {name} becomes a parameter of the declared type, and key order here is member order in all three generated files. It is also the copy deck transcribed from the Figma screens — fullNameHint is Yasmine Adel and deliveryAddress is Park Way 145 because those are the strings in the mock-ups, and categoriesChicken through categoriesVegetarian mirror the filter chips on the browse screen.
يفعل
لأن l10n.yaml يسمّيه template-arb-file، فهو وحده الذي يقرّر واجهة Dart المولّدة: كل مفتاح يصبح عضوًا، وكل {name} يصبح وسيطًا بالنوع المعلن، وترتيب المفاتيح هنا هو ترتيب الأعضاء في الملفات المولّدة الثلاثة. وهو أيضًا لوحة النصوص التي نُسخت من نماذج Figma: قيمة fullNameHint هي Yasmine Adel وقيمة deliveryAddress هي Park Way 145 لأنهما النصّان في التصميم، وcategoriesChicken إلى categoriesVegetarian تماثل شرائح التصفية في شاشة التصفح.
Needs
Valid JSON in UTF-8 — one trailing comma stops the generator for the whole app. One @ block for every message that takes an argument. A matching key in app_ar.arb, and a run of flutter gen-l10n or a build with generate: true.
يحتاج
JSON صحيح بترميز UTF-8 — ففاصلة زائدة واحدة تُوقف المولّد للتطبيق كله. وكتلة @ لكل رسالة تأخذ وسائط. ومفتاح مطابق في app_ar.arb. وتشغيل flutter gen-l10n أو بناء بـ generate: true.
Try it
Search the repository for notificationAdded. The single hit is the metadata block @notificationAdded on line 229; no message with that key exists in either ARB. The generator does not complain, and the generated class has no such getter. The orphan survived exactly because scripts/check_unused_arb.py iterates only keys that do not start with @ — the checker's field of view, not a generator bug.
جرّب
ابحث في المستودع عن notificationAdded: النتيجة الوحيدة هي كتلة البيانات الوصفية @notificationAdded في السطر ٢٢٩، ولا رسالة بهذا المفتاح في أيٍّ من الملفين. لا يعترض المولّد ولا يولّد عضوًا بهذا الاسم. بقي هذا اليتيم لأن scripts/check_unused_arb.py يمرّ على المفاتيح التي لا تبدأ بـ @ فقط — فهذا هو مجال رؤية الفاحص لا خلل في المولّد.
streetbite_capstone/lib/l10n/app_ar.arbl10n

The Arabic translation: the same 178 keys in the same order, and deliberately nothing else.

الترجمة العربية: المفاتيح الـ١٧٨ ذاتها وبالترتيب ذاته، ولا شيء آخر عن قصد.

Has
178 message keys, @@locale: ar, and zero @ metadata blocks. Twelve messages carry {placeholder} braces. Five values are byte-identical to their English twin: appName, emailHint, orderLineQuantity, arabic and english.
يحتوي
١٧٨ مفتاح رسالة و@@locale: ar وصفر من كتل @ الوصفية. اثنتا عشرة رسالة تحمل أقواس وسائط. خمس قيم مطابقة حرفيًا لنظيرتها الإنجليزية: appName وemailHint وorderLineQuantity وarabic وenglish.
Does
Only the template's metadata reaches the generated API, so this file needs no descriptions — but that also means the Arabic copy carries no in-file gloss for keys such as signInWithFingerprint or biometricSignInUnavailable. The five identical values are decisions, not oversights: a brand name, an e-mail address, and a multiplication sign are not translatable, and arabic plus english are endonyms — العربية and English in both locales — so the language toggle never shows a language name translated into the other language. Arabic-Indic digits are written inside the strings themselves (٦ أحرف على الأقل, بارك واي ١٤٥), while numbers produced at runtime come from L10nX.formatNumber.
يفعل
البيانات الوصفية التي تصل إلى الواجهة المولّدة تأتي من الملف الأم فقط، فلا حاجة هنا إلى تعليقات — لكن هذا يعني أن النص العربي لا يحمل شرحًا داخل ملفه لمفاتيح مثل signInWithFingerprint وbiometricSignInUnavailable. والقيم الخمس المطابقة قرارات لا سهوات: فاسم علامة تجارية، وعنوان بريد، وعلامة ضرب لا تُترجم، وأما arabic وenglish فهما اسمان ذاتيان (العربية وEnglish في كلتا اللغتين) حتى لا تظهر تسميةُ اللغة مترجمةً إلى اللغة الأخرى. والأرقام العربية الهندية مكتوبة داخل النصوص نفسها (٦ أحرف على الأقل وبارك واي ١٤٥)، أما الأرقام الناتجة وقت التشغيل فتأتي من L10nX.formatNumber.
Needs
The key set and the placeholder names of app_en.arb, which it must match one for one. A device font able to render Arabic — pubspec.yaml declares no fonts: block, so the app relies on the platform's Arabic fallback face.
يحتاج
مجموعة المفاتيح وأسماء الوسائط في app_en.arb، لأن عليه مطابقتها مفتاحًا بمفتاح. وخطّ في الجهاز يجيد العربية — فـpubspec.yaml لا يعلن أي كتلة fonts:، والتطبيق يعتمد على خطّ المنصّة الاحتياطي.
Try it
Count pluralLogic in the generated Arabic delegate: one, for orderItemsCount, and its branches are one and other — the two English categories. Arabic grammar has six plural categories (zero, one, two, few, many, other), so two items and five items both fall through to other and read 2 منتجات and 5 منتجات instead of منتجان and خمسة منتجات. A legible shortcut, not correct agreement — better to name it yourself in the defence than to be asked about it.
جرّب
عُدّ pluralLogic في المُنفِّذ العربي المولّد: واحدة، لـorderItemsCount، وفرعاها one وother — أي الفرعان الإنجليزيان. والنحو العربي له ست فئات جمع (صفر، وواحد، واثنان، وقليل، وكثير، وغير ذلك)، فحالتا «منتجان» و«خمسة منتجات» تهويان كلاهما إلى other وتظهران 2 منتجات و5 منتجات. اختصارٌ مقروء لا موافقةٌ نحوية صحيحة — وخير لك أن تسمّيه في مناقشتك من أن يُسأل عنه أنت.
streetbite_capstone/lib/l10n/generated/app_localizations.dartgen1203 lines

The contract every widget compiles against: 1203 generated lines, one abstract member per message, and the delegate that loads it.

العقد الذي تعتمد عليه كل معيار: ١٢٠٣ أسطر مولّدة، عضو مجرّد لكل رسالة، والمفوّض الذي يحمّله.

Has
abstract class AppLocalizations, fun lookupAppLocalizations
يحتوي
abstract class AppLocalizations, fun lookupAppLocalizations
Does
Declares abstract class AppLocalizations with 166 String get members and 12 methods for the messages that take arguments — 178 in all, one per key. AppLocalizations.of(context) is non-nullable because l10n.yaml sets nullable-getter: false: the ! did not disappear, it moved inside the generated file and off every call site. localizationsDelegates and supportedLocales are the two lists StreetBiteApp hands to MaterialApp, and the private _AppLocalizationsDelegate picks AppLocalizationsEn or AppLocalizationsAr when it loads. Each member carries the English sentence in its doc comment: 178 lines read In en, this message translates to and 173 read No description provided — the honest measure of how much guidance the template gives a translator.
يفعل
يُعلن abstract class AppLocalizations بـ١٦٦ عضو String get و١٢ دالة للرسائل التي تأخذ وسائط — ١٧٨ بالمجمل، واحدٌ لكل مفتاح. وAppLocalizations.of(context) غير قابل للعدم لأن l10n.yaml يضبط nullable-getter: false: لم تختفِ ! بل انتقلت إلى داخل الملف المولّد وعن مواضع النداء كلها. والقائمتان localizationsDelegates وsupportedLocales هما ما يعطيه StreetBiteApp إلى MaterialApp، ويختار المفوّض الخاص _AppLocalizationsDelegate عند التحميل بين AppLocalizationsEn وAppLocalizationsAr. ويحمل كل عضو الجملة الإنجليزية في تعليق توثيقه: ١٧٨ سطرًا تقول In en, this message translates to و١٧٣ تقول No description provided — مقياسٌ صادق لمقدار ما يمنحه الملف الأم من دليل للمترجم.
Needs
packages: flutter, flutter_localizations, intl; project files: l10n/generated/app_localizations_ar.dart, l10n/generated/app_localizations_en.dart + 0 more
يحتاج
حزم: flutter, flutter_localizations, intl؛ ملفات المشروع: l10n/generated/app_localizations_ar.dart, l10n/generated/app_localizations_en.dart + 0 أخرى
Try it
Run flutter gen-l10n with nothing else changed, then git diff. An empty diff is the proof that committed generated code matches its ARB source; that reproducibility, not convenience, is what makes checking it in safe. Then count the lines matching No description provided and decide whether five descriptions out of 178 is enough for a project you intend to hand over.
جرّب
شغّل flutter gen-l10n دون أي تعديل آخر ثم git diff. أن يبقى فارغًا هو الدليل على أن الشيفرة المولّدة المودَعة تطابق مصدرها في ARB؛ فهذه القابلية للتكرار لا الراحة هي التي تجعل التزامها آمنًا. ثم عُدّ الأسطر التي تطابق No description provided وقرّر هل خمس تعليقات من ١٧٨ تكفي في مشروع تنوي أن تسلّمه.
streetbite_capstone/lib/l10n/generated/app_localizations_en.dartgen597 lines

The English implementation: 597 lines that answer every abstract member with a literal.

التنفيذ الإنجليزي: ٥٩٧ سطرًا تجيب عن كل عضو مجرّد بنصٍّ حرفي.

Has
class AppLocalizationsEn
يحتوي
class AppLocalizationsEn
Does
class AppLocalizationsEn extends AppLocalizations, with a constructor defaulting to 'en'. Plain messages become one-line getters; the twelve messages with arguments become methods that interpolate them; the single plural becomes intl.Intl.pluralLogic(count, locale: localeName, one: '1 item', other: '$count items'). The ARB's doubled apostrophe is already resolved here: Don''t in the source is a normal apostrophe inside a Dart string quoted in single quotes — that collapse is exactly what use-escaping: true buys, and without it the app would print Don''t have an account? to the user.
يفعل
class AppLocalizationsEn extends AppLocalizations ببنية افتراضية هي 'en'. الرسائل البسيطة تصبح دوال جلب من سطر واحد، والاثنتا عشرة رسالة التي تأخذ وسائط تصبح دالات تُدخلها، والصيغة الوحيدة للجمع تصبح intl.Intl.pluralLogic(count, locale: localeName, one: '1 item', other: '$count items'). والفاصلة العليا المضعّفة في ARB محلولة هنا بالفعل: Don''t في المصدر تصبح فاصلة عليا واحدة داخل نص Dart مُطوَّف بعلامتي اقتراض مفردتين — وهذا هو ثمن use-escaping: true بالضبط؛ فبدونه كان سيظهر للمستخدم Don''t have an account? كما هي.

packages: intl; project files: l10n/generated/app_localizations.dart + 0 more
يحتاج

Try it
Search this file for pluralLogic: one hit, and its other branch interpolates the raw count. Compare it with L10nX.formatNumber, which goes through NumberFormat.decimalPattern: the badge under an order prints Latin digits in Arabic while the prices print Arabic-Indic ones. Two honest ways to be inconsistent, and only one of them is tested.
جرّب
ابحث عن pluralLogic في هذا الملف: نتيجة واحدة، وفرع other فيها يُدخل count خامًا. وقارنه بـL10nX.formatNumber الذي يمرّ على NumberFormat.decimalPattern: شارة عدد المنتجات تحت الطلب تطبع أرقامًا لاتينية في العربية بينما الأسعار تطبع أرقامًا هندية عربية — طريقتان شريفتان على الاضطراب، وواحدة منهما فقط مختبَرة.

The Arabic implementation: the same 178 members with Arabic literals, ten lines shorter.

التنفيذ العربي: الأعضاء الـ١٧٨ ذاتها بنصوص عربية، أقصر بعشرة أسطر.

Has
class AppLocalizationsAr
يحتوي

Does
class AppLocalizationsAr extends AppLocalizations, constructor defaulting to 'ar', 587 lines against the English file's 597. The difference is formatting only — the formatter wraps long Arabic strings sooner — because the member set is provably identical. Nothing in this file knows about right-to-left: direction, mirroring, digit shapes and month names come from flutter_localizations plus the widgets' own Directionality, which is why the app must register that delegate in MaterialApp and not merely ship the strings.

How this document was made. Written against commit 07b200f. Every card was produced by reading the file it describes; the line counts, declaration names and import lists are extracted from the source tree by _audit/imports.py, and _audit/build_guide.py refuses to build if a card points at a Dart file that no longer exists. Nothing here is remembered from a previous draft.

Companion documents. docs/code-doc/index.html explains the concepts (architecture, state, errors, security) layer by layer; this guide answers the other question — what is each file for. docs/StreetBite_Capstone_Report_EN-AR.pptx is the slide deck for the defence itself.

Language. Both columns are on by default; the sidebar switches to English or Arabic only. Paths, identifiers and code are never translated, because Either<Failure, List<MealEntity>> reads the same in either language.

كيف صُنعت هذه الوثيقة. كُتبت عند الالتزام 07b200f. وكل بطاقة نُقلت بعد قراءة الملف الموصوف؛ وأعداد الأسطر وأسماء التصريحات وقوائم الاستيراد تُستخرج من شجرة المصدر بواسطة _audit/imports.py، و_audit/build_guide.py يرفض البناء إذا أشارت بطاقة إلى ملف Dart لم يعد موجودًا. ولا شيء هنا من الاستذكار.

الوثائق المكمّلة. يشرح docs/code-doc/index.html المفاهيم (المعمارية، الحالة، الأخطاء، الحماية) طبقة طبقة؛ أما هذا الدليل فيجيب عن السؤال الآخر: ما وظيفة كل ملف. وملف docs/StreetBite_Capstone_Report_EN-AR.pptx هو العرض التقديمي للمناقشة.

اللغة. العمودان ظاهران افتراضيًا، ويحوّلهما الشريط الجانبي إلى الإنجليزية أو العربية وحدها. ولا تُترجَم المسارات والمعرّفات والشفرة أبدًا، لأن Either<Failure, List<MealEntity>> تُقرأ بالشكل نفسه في اللغتين.
