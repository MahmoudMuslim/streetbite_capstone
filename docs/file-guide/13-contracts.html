13 ‏lib/domain/repositories — six interfaces, and the seam that holds the whole architecture together‏lib/domain/repositories — ست واجهات، والوصلة التي تمسك العمارة كلها

Nine lines to forty-two: these six files are the entire vocabulary the app has for "get data". Check what they import — core/error/either.dart, core/error/failures.dart and other entities. Never Flutter, never a package, never lib/data. That restriction is dependency inversion stated as an import list rather than as a slogan.

Every Cubit depends on one of these; every implementation in lib/data/repositories declares implements one of these; and injection.dart is the single file that knows both sides.

من تسعة أسطر إلى اثنين وأربعين: هذه الملفات الستة هي مفردات التطبيق كلها لقول «اجلب البيانات». انظر ماذا تستورد: core/error/either.dart وcore/error/failures.dart وكيانات أخرى. لا Flutter أبدًا، ولا حزمة، ولا lib/data. هذا القيد هو عكس الاعتمادية معلنًا كقائمة استيراد لا كشعار.

كل Cubit يعتمد على واحدة منها؛ وكل تطبيق في lib/data/repositories يعلن implements واحدة منها؛ وinjection.dart الملف الوحيد الذي يعرف الطرفين.

streetbite_capstone/lib/domain/repositories/auth_repository.dartdomain43 lines

The widest contract in the app: seven members that cover sign-up, login, restore, sign-out, the biometric opt-in and a live stream.

أوسع عقد في التطبيق: سبعة أعضاء تغطي التسجيل والدخول والاستعادة والخروج وموافقة القياس البيومتري وتدفقًا حيًا.

Has
abstract interface class AuthRepository with restoreSession(), login(), signUp(), logout(), the biometricSignInEnabled getter, setBiometricSignInEnabled() and authStateChanges().
يحتوي
abstract interface class AuthRepository فيها restoreSession() وlogin() وsignUp() وlogout() وقارئ biometricSignInEnabled وsetBiometricSignInEnabled() وauthStateChanges().
Does
Two decisions are visible in the shape of this file alone. The first: every fallible method returns Either<Failure, T>, so the failure type is part of the contract and a Cubit cannot pretend nothing went wrong. The second: the biometric opt-in lives here rather than in a settings contract, and the doc comment argues why — the flag changes what restoreSession() means, because with the opt-in on a live session is a candidate for sign-in rather than sign-in itself. The signature also carries one documented obligation for callers: displayName must arrive already capitalised, which is the contract version of the rule the presentation layer follows.
يفعل
قراران يظهران من شكل الملف وحده. الأول: كل دالة قابلة للفشل ترجع Either<Failure, T>، فيكون نوع الفشل جزءًا من العقد ولا يستطيع Cubit أن يتظاهر بأن شيئًا لم يحدث. والثاني: موافقة القياس البيومتري مقيمة هنا لا في عقد إعدادات، ويحاجج التعليق بالسبب — لأن الوسم يغيّر معنى restoreSession() نفسه، فمع الموافقة تكون الجلسة الحيّة مرشّحة للدخول لا دخولًا. ويحمل التوقيع أيضًا التزامًا موثقًا على المستدعي: أن يصل displayName مضبوط الحرف الأول سلفًا، وهو نسخة العقد من القاعدة التي تلتزم بها طبقة العرض.

streetbite_capstone/lib/domain/repositories/meal_repository.dartdomain20 lines

Two methods for the whole Home feed — and a doc comment that teaches the patterns.

دالتان لكل موجة الرئيسية — وتعليق يدرّس الأنماط.

Has
abstract interface class MealRepository with getMeals() and getHotOffers().
يحتوي
abstract interface class MealRepository وفيها getMeals() وgetHotOffers().
Does
The interface is deliberately silent about where meals come from: no URL, no cache key, no limit. The doc comment names dependency inversion and the Factory pattern, and points at MealRepositoryImpl.selectDataSource() as the place where the runtime choice is made — so the contract reads like documentation for the requirement it satisfies. Its own promise is narrow and explicit: getMeals() emits CacheFailure when there is neither a good response nor a usable local copy, which is the only situation in which the Home screen is allowed to show an error.
يفعل
تسكت الواجهة عمدًا عن مكان قدوم الأصناف: لا رابط، ولا مفتاح مخزون، ولا limit. ويسمّي التعليق عكس الاعتمادية ونمط المصنع، ويشير إلى MealRepositoryImpl.selectDataSource() بوصفه الموضع الذي يُتَّخذ فيه قرار الزمن الحقيقي — فيُقرأ العقد كأنه وثيقة للمتطلب الذي يلبيه. ووعده هو نفسه ضيّق وصريح: تُصدر getMeals() CacheFailure حين لا جواب صالح ولا نسخة محلية صالحة، وهو الوضع الوحيد الذي يُسمح فيه لشاشة الرئيسية أن تعرض خطأ.

streetbite_capstone/lib/domain/repositories/order_repository.dartdomain17 lines

Checkout's entire view of persistence: write an order, read a history.

كل ما تراه شاشة الدفع من التخزين: اكتب طلبًا، واقرأ تاريخًا.

Has
abstract interface class OrderRepository with placeOrder({user, order}) and getOrderHistory(uid).
يحتوي
abstract interface class OrderRepository وفيها placeOrder({user, order}) وgetOrderHistory(uid).
Does
placeOrder() returns the stored document id inside the Either, which is what lets the success route navigate to a receipt without a second round-trip. Taking the UserEntity as well as the order is a contract-level statement of the Firestore layout: the id is the path orders/{uid}/items/{orderId}, so the caller must supply both halves. getOrderHistory() promises newest-first, and that promise is why the Orders tab does no sorting of its own.
يفعل
ترجع placeOrder() معرّف الوثيقة المخزّنة داخل Either، وهذا ما يسمح لمسار النجاح بالانتقال إلى إيصال بلا رحلة ثانية. وأما قبول UserEntity مع الطلب فهو إقرار على مستوى العقد بتخطيط Firestore: فالمعرّف هو المسار orders/{uid}/items/{orderId}، فيجب أن يعطي المستدعي الطرفين. وتعد getOrderHistory() بالأحدث أولًا، وهذا الوعد هو سبب عدم ترتيب تبويب الطلبات لنفسه.

ملفات المشروع: core/error/either.dart, core/error/failures.dart, domain/entities/order_entity.dart, domain/entities/user_entity.dart + 0 أخرى

streetbite_capstone/lib/domain/repositories/profile_repository.dartdomain20 lines

Three methods for one document at users/{uid}.

ثلاث دالات لوثيقة واحدة في users/{uid}.

Has
abstract interface class ProfileRepository with getProfile(uid), saveProfile(user) and updatePhotoUrl({uid, photoUrl}).
يحتوي
abstract interface class ProfileRepository وفيها getProfile(uid) وsaveProfile(user) وupdatePhotoUrl({uid, photoUrl}).
Does
The nullability here is the design: getProfile() returns Either<Failure, UserEntity?>, so 'no document yet' is a legal answer and not a failure — which is exactly the state a brand-new account is in between sign-up and the first profile write. saveProfile() is documented as create-or-merge, matching the SetOptions(merge: true) the implementation uses, and updatePhotoUrl() returns the URL it stored so the caller can paint the avatar without re-reading the document.
يفعل
القابلية للعدم هنا هي التصميم: ترجع getProfile() Either<Failure, UserEntity?>، فيكون «لا وثيقة بعد» جوابًا مشروعًا لا فشلًا — وهو بالضبط حالة حساب جديد بين التسجيل وأول كتابة للملف الشخصي. ويوثَّق saveProfile() إنشاءًا أو دمجًا موافقًا SetOptions(merge: true) الذي يستخدمه التطبيق، وترجع updatePhotoUrl() الرابط الذي خزنته حتى ترسم الواجهة صورتها بلا إعادة قراءة الوثيقة.

streetbite_capstone/lib/domain/repositories/favourite_repository.dartdomain19 lines

The heart button's whole backend: two methods, nine words of doc each.

خلفيّة زر القلب كلها: دالتان، وتسع كلمات تعليق لكل واحدة.

Has
abstract interface class FavouriteRepository with toggleFavourite({uid, meal}) and getFavourites(uid).
يحتوي
abstract interface class FavouriteRepository وفيها toggleFavourite({uid, meal}) وgetFavourites(uid).
Does
toggleFavourite() returns Either<Failure, bool> and the bool is documented as 'the meal ended up saved': one round-trip tells the UI both that nothing failed and which SnackBar to show, so no second read is needed to find out what just happened. Naming is worth noticing — the contract speaks of a toggle (intent) while Firestore offers only create and delete (operations); translating between those two vocabularies is the implementation's job, which is precisely why the interface exists.
يفعل
ترجع toggleFavourite() Either<Failure, bool> والقيمة المنطقية موثّقة بأنها «الصحن صار محفوظًا»: فرحلة واحدة تخبر الواجهة بأن شيئًا لم يفسد وبعنوان الشريط الذي عليها عرضه، فلا حاجة لقراءة ثانية لمعرفة ماذا جرى. والاسم يستحق الوقوف عنده: يتحدث العقد عن تبديل (نية) بينما لا يوفر Firestore إلا إنشاء وحذفًا (عمليّات)؛ والترجمة بين المعجمين مهمة التطبيق، وهذا بالضبط سبب وجود الواجهة.

يحتاج
ملفات المشروع: core/error/either.dart, core/error/failures.dart, domain/entities/meal_entity.dart + 0 أخرى

streetbite_capstone/lib/domain/repositories/vendor_repository.dartdomain10 lines

Nine lines, one method — the whole map's data contract.

تسعة أسطر ودالة واحدة — عقد بيانات الخريطة كله.

Has
abstract interface class VendorRepository with getNearbyVendors().
يحتوي
abstract interface class VendorRepository وفيها getNearbyVendors().
Does
Even a call that can never fail today is declared to return Either<Failure, List<VendorEntity>>, because consistency at this boundary is worth more than the two characters it costs: a Cubit can treat every repository the same way, and a future networked implementation does not change the shape of anything above it. This is the smallest file in lib/domain/ and the clearest illustration that a contract is about the shape of an answer, not about how hard the answer was to produce.
يفعل
حتى نداء لا يستطيع أن يفشل اليوم معلَن كـ Either<Failure, List<VendorEntity>>، لأن الاتساق عند هذا الحد أغلى من الحرفين الذين يكلّفهما: فيستطيع أي Cubit أن يعامل كل المستودعات بطريقة واحدة، ولا يغيّر تطبيق شبكي مستقبلًا شكل أي شيء فوقه. وهذا أصغر ملف في lib/domain/ وأنصع مثال على أن العقد عن شكل الجواب لا عن مدى صعوبة إنتاجه.

How this document was made. Written against commit 07b200f. Every card was produced by reading the file it describes; the line counts, declaration names and import lists are extracted from the source tree by _audit/imports.py, and _audit/build_guide.py refuses to build if a card points at a Dart file that no longer exists. Nothing here is remembered from a previous draft.

Companion documents. docs/code-doc/index.html explains the concepts (architecture, state, errors, security) layer by layer; this guide answers the other question — what is each file for. docs/StreetBite_Capstone_Report_EN-AR.pptx is the slide deck for the defence itself.

Language. Both columns are on by default; the sidebar switches to English or Arabic only. Paths, identifiers and code are never translated, because Either<Failure, List<MealEntity>> reads the same in either language.

كيف صُنعت هذه الوثيقة. كُتبت عند الالتزام 07b200f. وكل بطاقة نُقلت بعد قراءة الملف الموصوف؛ وأعداد الأسطر وأسماء التصريحات وقوائم الاستيراد تُستخرج من شجرة المصدر بواسطة _audit/imports.py، و_audit/build_guide.py يرفض البناء إذا أشارت بطاقة إلى ملف Dart لم يعد موجودًا. ولا شيء هنا من الاستذكار.

الوثائق المكمّلة. يشرح docs/code-doc/index.html المفاهيم (المعمارية، الحالة، الأخطاء، الحماية) طبقة طبقة؛ أما هذا الدليل فيجيب عن السؤال الآخر: ما وظيفة كل ملف. وملف docs/StreetBite_Capstone_Report_EN-AR.pptx هو العرض التقديمي للمناقشة.

اللغة. العمودان ظاهران افتراضيًا، ويحوّلهما الشريط الجانبي إلى الإنجليزية أو العربية وحدها. ولا تُترجَم المسارات والمعرّفات والشفرة أبدًا، لأن Either<Failure, List<MealEntity>> تُقرأ بالشكل نفسه في اللغتين.
